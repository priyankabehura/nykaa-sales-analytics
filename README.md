# 💄 Nykaa Beauty & Personal Care — Sales Analytics Dashboard

An interactive end-to-end Excel sales dashboard designed to analyze revenue trends, top-selling categories, and customer order behaviors using raw transaction data.

---

## 📌 Project Overview
* **Objective:** Track and analyze beauty & personal care sales performance to uncover key drivers of revenue and city-level demand.
* **Tools Used:** Microsoft Excel (PivotTables, PivotCharts, Slicers, Report Connections, KPI Design)

---

## 📊 Key Highlights & KPIs
* **Total Net Sales:** ₹19,06,646
* **Total Orders:** 750
* **Average Order Value (AOV):** ₹2,542
* **Top Category:** Fragrance (₹5,43,327 | 29% total share)
* **Top Performing City:** Bengaluru (₹2,24,419)
* **Peak Sales Month:** September (₹2,17,240)
* **Top Sales Day:** Friday

---

## 🛠️ Dashboard Features
* **Interactive Slicers:** Connected across multiple pivot tables for Month, Category, and Channel breakdown.
* **Custom KPI Cards:** Clean summary of core metrics for quick business insights.
* **Visual Breakdown:** Category share donut chart, Top 5 brands/cities horizontal bars, and a 12-month sales trend line.
